# MyFences visual direction

The desktop is the work surface. Groups should quietly organize icons while leaving the wallpaper visible. The reference is the restrained translucent group treatment in Stardock Fences, not a dashboard.

- Group surface: charcoal blue (#253344), configurable opacity, 8 DIP corners, fine light outline. Header 36 DIP; Segoe UI Variable / Segoe UI typography, white labels with a restrained text shadow over wallpaper.
- Icon grid: original Shell icons, 40 DIP images in 86 × 94 DIP cells, readable two-line names, visible selection and keyboard focus. Long names have full-path tooltips; missing files have an explicit status.
- Settings: a light native utility window with a compact masthead, rule table as the primary work area, and a separate appearance tab. Blue denotes the main action and keyboard focus; no decorative metrics or gradients.
- Interaction: title dragging, edge resizing, collapse button, multi-selection, drag insertion feedback. Empty groups explain the next action. Errors stay actionable and recovery preserves the saved layout.
- Finish: inspect the real WPF settings and group surfaces in both languages, empty and populated states, narrow groups and long labels. Verify desktop attachment separately from standalone preview rendering.
